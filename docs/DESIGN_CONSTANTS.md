# Design Constants — STEAL THE QUESTIONS

These are the visual anchors to protect the game's identity.

## 1. Card
The card is the hero object. It must be visually recognizable before the player reads text.

## 2. Card entrance
Draw from deck -> slide to center -> flip -> settle.

## 3. Question layout
Question lives inside the active card. Three large answer choices sit below it.

## 4. Answer interaction
Tap -> pressed state -> brief freeze -> result feedback.

## 5. Result states
Correct: energetic confirmation.
Wrong: clear impact/failure.
Timeout: distinct time-expired state.

## 6. Timer
Short visual countdown integrated with the active card area.

## 7. Sound identity
Dedicated short sounds for card draw, card flip, answer select, correct, wrong, timeout, win, and steal.

## 8. Steal sequence
Winner sees the opponent's 10 duel cards face-down -> chooses one -> reveals -> steal confirmation -> card transfers into winner collection.

## 9. Screen language
Premium, dark, competitive, clean. Avoid school-quiz or generic game-show styling.

## 10. Motion rule
Fast, deliberate, reusable transitions. No decorative animation that slows the core loop.

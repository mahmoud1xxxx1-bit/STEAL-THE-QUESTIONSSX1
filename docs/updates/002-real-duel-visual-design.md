# UPDATE 002 — Real Duel Visual Design

## Objective
Replace the technical prototype styling with the first real art direction for STEAL THE QUESTIONS.

## Visual identity
- Brighter blue/indigo/purple arena instead of a flat near-black screen.
- Layered ambient lighting for depth.
- The card is the hero object.
- Card face uses a bright premium surface for comfortable reading.
- Card back uses a distinct holographic geometric identity.
- Gold marks rarity and the winning/steal moment.
- Cyan marks interaction and time.
- Coral marks urgency/wrong states.

## Bilingual foundation
- English and Arabic are both implemented in the duel prototype.
- Language toggle is visible.
- Arabic uses RTL layout and right-aligned question/answers.
- English uses LTR layout.
- Text containers are designed to adapt to different string lengths.

## Core duel presentation
- 10-card deck shown as a compact visual rail.
- 7 active duel questions are clearly represented.
- 20-second timer integrated into the active card.
- Card draw/enter and 3D flip animation.
- Three large answer buttons.
- Correct/wrong feedback.
- Duel completion screen.
- Steal screen showing ten opponent cards.
- Card selection, reveal, steal confirmation, and claimed state.

## Scope lock
This update remains visual/interaction only.
No Firebase, account data, final question bank, subscription, or live matchmaking is added.

# UPDATE 004 — Clear Game Visual Language

## Objective
Replace the previous sharp/flat prototype look with a clear game interface that is designed around readable hierarchy, physical card presence, and a restrained competitive-arena feel.

## Visual direction
- Deep slate arena background with a subtle floor/grid and framed play area.
- Strong player panels at the top with clear score hierarchy.
- Centered question progress panel.
- Real card composition: outer frame, inner frame, ornamental corners, question plaque, answer plaques, rarity badge, and timer.
- The card uses warm ivory and dark navy for high readability instead of black text on pale/weak surfaces.
- Decks are represented as visible physical stacks on wide screens.
- The bottom deck rail uses actual mini-card shapes instead of plain numbered chips.
- Answer choices use dark plaques with clear letter medallions and high-contrast text.
- Steal cards use the same physical-card language so the steal phase belongs to the same game.

## Scope
Only visual/UI work in `lib/main.dart`.
No Firebase, matchmaking, economy, subscription, question-bank, or game-rule changes.

## Goal
The preview should read immediately as a game session, not as a generic app mockup.
